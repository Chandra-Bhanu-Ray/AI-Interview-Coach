# AI Interview Coach

An AI-powered platform that helps students prepare for interviews through practice questions, answer evaluation, and personalized feedback.

## Features
- AI-generated interview questions
- Interactive interview practice
- Answer evaluation
- Weakness Detection System
- Personalized feedback and improvement suggestions

## Technologies Used
- Python
- JavaScript
- React
- AI / LLM APIs

## How It Works
1. Start an interview practice session.
2. Answer the generated questions.
3. AI evaluates your answers.
4. The system identifies weaknesses.
5. Get feedback and suggestions for improvement.

## Project Objective
To help students improve their interview skills and confidence using AI-powered practice and evaluation.
